The `foundation.s3` activities at `release` or `beta` status; `beta` ones are
marked. Each also takes the optional `integration_id` and
`integration_name` arguments, which the
[Activities](https://docs.popcorn.ai/activities.md) page explains.

### `foundation.s3.download`

Download an S3 object and return its bytes base64-encoded.

Reads `s3://{bucket}/{key}` and returns `data` (base64), the
`size_bytes`, and the object `etag`.

```yaml
- id: <step>
  activity: foundation.s3.download
  args:
    bucket: <string>
    key: <string>
```

**Arguments**

| Argument | Type | Required | Notes |
|---|---|---|---|
| `bucket` | string | yes |  |
| `key` | string | yes |  |

**Returns**

| Field | Type | Notes |
|---|---|---|
| `data` | string |  |
| `size_bytes` | integer |  |
| `etag` | string, optional |  |

### `foundation.s3.upload`

Upload bytes to an S3 object.

Writes the base64-decoded `body` to `s3://{bucket}/{key}` (with an
optional `content_type`) and returns the `s3_uri`, `size_bytes`, and
`etag`.

```yaml
- id: <step>
  activity: foundation.s3.upload
  args:
    bucket: <string>
    key: <string>
    body: <string>
```

**Arguments**

| Argument | Type | Required | Notes |
|---|---|---|---|
| `bucket` | string | yes |  |
| `key` | string | yes |  |
| `body` | string | yes |  |
| `content_type` | string, optional | no |  |

**Returns**

| Field | Type | Notes |
|---|---|---|
| `s3_uri` | string |  |
| `size_bytes` | integer |  |
| `etag` | string, optional |  |
