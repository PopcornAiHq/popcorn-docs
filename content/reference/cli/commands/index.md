Every command `popcorn` 0.63.1 lists in its help menu, A to Z: 87 with
their subcommands. Each page shows the Usage line and arguments;
`popcorn <command> --help` describes the one you have installed.

- **[`api`](https://docs.popcorn.ai/cli/commands/other.md#api)** — Raw API call (escape hatch, like gh api)
- **[`app`](https://docs.popcorn.ai/cli/commands/app.md)** — App bundles — fork, check out, edit and publish one
- **[`auth`](https://docs.popcorn.ai/cli/commands/auth.md)** — Auth commands (login, logout, status, token)
- **[`channel`](https://docs.popcorn.ai/cli/commands/channel.md)** — Channel commands (archive, create, delete, edit, info, invite, join, kick, leave, list, templates)
- **[`channel-config`](https://docs.popcorn.ai/cli/commands/channel-config.md)** — Channel config — inspect it against the flows, and edit it
- **[`commands`](https://docs.popcorn.ai/cli/commands/other.md#commands)** — Dump CLI schema as JSON for programmatic discovery
- **[`completion`](https://docs.popcorn.ai/cli/commands/other.md#completion)** — Generate shell completions (bash, zsh)
- **[`doctor`](https://docs.popcorn.ai/cli/commands/other.md#doctor)** — Diagnose local setup: auth, API reachability, env, config
- **[`env`](https://docs.popcorn.ai/cli/commands/other.md#env)** — Show or switch environment/profile
- **[`flow`](https://docs.popcorn.ai/cli/commands/flow.md)** — Flow commands (activities, validate, import, list, get, run, runs list, runs get, runs timeline, runs cancel)
- **[`message`](https://docs.popcorn.ai/cli/commands/message.md)** — Message commands (answer, delete, download, edit, get, list, questions, react, search, send, threads)
- **[`schedule`](https://docs.popcorn.ai/cli/commands/schedule.md)** — Scheduled-flow commands (list, get, trigger)
- **[`table`](https://docs.popcorn.ai/cli/commands/table.md)** — Agent-store commands (list, schema, rows, import, row create/get/patch/delete, scalar list/get/set, audit)
- **[`upgrade`](https://docs.popcorn.ai/cli/commands/other.md#upgrade)** — Upgrade popcorn to the latest version
- **[`version`](https://docs.popcorn.ai/cli/commands/other.md#version)** — Show version (--check to check for updates)
- **[`webhook`](https://docs.popcorn.ai/cli/commands/webhook.md)** — Webhook commands (create, list, get, update, delete, override-rules get/set, deliveries, event-types, send)
- **[`whoami`](https://docs.popcorn.ai/cli/commands/other.md#whoami)** — Show current user and workspace
- **[`workspace`](https://docs.popcorn.ai/cli/commands/workspace.md)** — Workspace commands (check-access, inbox, list, switch, users)
